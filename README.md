Program do obsługi klasy:
Program napisany w C++. Służy do wczytywania i wyświetlania informacji o uczniach.

Jak działa program?:
Po uruchomieniu program prosi o:
nazwę klasy,
nazwisko wychowawcy.
Następnie program otwiera plik uczniowie.txt i pobiera z niego dane uczniów.
Na końcu wyświetla listę uczniów na ekranie.

Plik uczniowie.txt:

Dane uczniów powinny być zapisane w takim formacie:
Imię Nazwisko Numer

Przykład:
Jan Kowalski 1
Anna Nowak 2
Piotr Wiśniewski 3

Program może wczytać maksymalnie 30 uczniów.

Pliki:
main.cpp - kod programu
uczniowie.txt - dane uczniów

Technologie:
Program został napisany w języku C++.
Wykorzystuje biblioteki:
iostream
string
fstream
